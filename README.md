# Биометрический КПП

Локальный учебный прототип системы биометрической аутентификации для контроля доступа на режимный объект с использованием распознавания лица. Backend: Python/FastAPI, хранение: SQLite, вектор лица: 128 чисел. Кадры камеры обрабатываются в оперативной памяти и не записываются.

## Запуск

Нужен Python 3.10–3.12. Создайте виртуальное окружение, установите зависимости и запустите сервер:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:8000>. Браузеру потребуется разрешение на камеру. Для Windows активируйте окружение командой `.venv\\Scripts\\activate`.

Запустите сервер только на loopback-интерфейсе. Файл базы данных `kpp.sqlite3` создается рядом с приложением; путь можно изменить переменной `KPP_DB_PATH`. Порог сравнения настраивается переменной `KPP_MATCH_THRESHOLD` (по умолчанию 0.52), порог выявления повторной регистрации — `KPP_DUPLICATE_THRESHOLD` (по умолчанию 0.45).
